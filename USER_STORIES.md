# Learner App - User Stories

## User Story 1 - Sign Up

As a new learner, I want to create an account using my username, email, and password so that I can use the application.

## User Story 2 - Login

As a registered learner, I want to log in using my email and password so that I can access my account.

## User Story 3 - View Learning Content

As a learner, I want to view learning content from an external API on the home screen so that I can access available learning information.

## User Story 4 - View Content Details

As a learner, I want to open a learning item and view its details so that I can understand the selected content.

## User Story 5 - Save Favorites

As a learner, I want to save learning items to my favorites so that I can access them later.

## User Story 6 - View Profile

As a learner, I want to view my profile and saved favorites so that I can manage my personal information and saved content.

## User Story 7 - Access Settings Menu

As a learner, I want to access a settings menu so that I can navigate to settings, notifications, profile, and logout.

## User Story 8 - Configure Application Settings

As a learner, I want to configure notifications, dark mode, and language preferences so that the application matches my preferences.

## User Story 9 - Receive Notifications

As a learner, I want to receive notifications from the application so that I can be informed about important events.
